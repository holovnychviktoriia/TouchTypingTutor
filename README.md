# Touch Typing Tutor

Десктопний додаток для навчання друку сліпим методом.
Курсова робота з дисципліни «Основи програмування та алгоритмічні мови».

## Технології

- C# 12, .NET 10
- Avalonia UI 11
- JSON для збереження даних

## Запуск

```bash
dotnet run
```
